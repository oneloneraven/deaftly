# MVP requirements traceability

Date: 2026-11-13. Covers issue #58 (MVP release), acceptance criterion "Every MVP requirement is traced to a merged story and verified on a device".

This document traces every MVP requirement in [requirements](requirements.md) to the stories and pull requests that delivered it, to the automated tests that exercise it, and to a check the owner can perform on a phone. It is the record the device pass is run against, and the list of gaps to close before the MVP is released.

## How to read it

- **Delivered by** lists the closed issues (and the merged pull requests that closed them) that built the requirement. Where an issue's body says "Covers requirements …", that was checked against the code. Later changes that reshaped a requirement (for example #125, which replaced the split-screen chat with Face to face) are listed too.
- **Automated evidence** names the test classes, and test methods where one method carries the requirement. Unit and Robolectric tests run in `./gradlew check`; Roborazzi screenshot tests (`*ScreenshotTest`) record light, dark and large-font renderings and are named only where they matter. Tests marked "(device)" are instrumented tests that run on an emulator or phone in the device-tests workflow.
- **Device check** is confirmed through user testing with deaf users (#56): the test users use the app on their own phones and report anything that doesn't work. Each cell describes what that use should show; until the sessions run, it reads "To verify".
- **Status** is one of:
  - **Met**: built, and exercised by an automated test or check.
  - **Met — untested**: built, but nothing automated exercises it.
  - **Partly met**: built, with something missing (stated).
  - **Not met**: not built, or not built enough to count (stated).
  - **Superseded**: replaced by a later decision (stated).
- A status is Met only where the implementing code and a test were both found. Where a test covers only part of a requirement, the row says which part.

## Gaps

Each item below is Not met, Partly met, or met without an automated test, with what closes it.
